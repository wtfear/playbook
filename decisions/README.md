# Operating Decision Records (ODRs)

This directory serves as the formal repository for all Operating and Architectural Decision Records of the agency.

## Purpose

Major decisions regarding business models, technical architecture, tool selection, commercial structures, and governance rules require documented rationale. ODRs prevent circular debates, capture historical context, and record trade-offs and alternatives considered.

## Conventions

- **Template:** Use [`../templates/decision-record-template.md`](../templates/decision-record-template.md).
- **Naming Pattern:** `odr-[number]-[short-title].md` (e.g., `odr-001-repository-architecture.md`).
- **Authority:** Approved ODRs represent official, binding agency direction.
- **Cross-Linking:** Any policy, playbook, or workflow born from a decision must link back to its corresponding ODR.
